# Experiment 1: Create a Web Page with HTML5 Elements

## Objective
To create a web page using HTML5 elements, forms, tables, multimedia, and semantic tags.

## Concepts Covered
- Basic HTML5 document structure.
- Semantic elements like `header`, `nav`, `main`, `section`, and `footer`.
- Text formatting and ordered, unordered, and description lists.
- Tables using `table`, `tr`, `th`, and `td`.
- Forms with different input types and validation.
- Multimedia using `img`, `audio`, and `video`.
- Interactive elements like `details`, `dialog`, and `datalist`.
- Basic CSS styling and JavaScript interactions.

## Requirements
- VS Code or any text editor.
- Google Chrome, Firefox, or Edge.

## How to Run
1. Save the HTML code in a file named `index.html`.
2. Open the file in a web browser.
3. Test the navigation links, form inputs, multimedia, and interactive elements.

## Expected Output
A complete HTML5 web page demonstrating different HTML elements, forms, tables, multimedia, and interactive features.

## Learning Outcome
Understand how to create structured, accessible, and interactive web pages using HTML5.
