# Experiment 12: Node.js, Express.js, and EJS Templating

## Objective
To build server-side applications using Node.js and Express.js, handle HTTP requests, and render dynamic web pages using EJS.

## Files
- `app.js` – Creates the Express server and defines routes.
- `package.json` – Stores project details, dependencies, and scripts.
- `views/home.ejs` – Displays the home page.
- `views/users.ejs` – Displays a list of users.
- `views/profile.ejs` – Displays user profile details.

## Concepts Covered
- Node.js and NPM basics.
- Express server and routing.
- HTTP GET and POST requests.
- URL parameters and query parameters.
- JSON and HTML responses.
- EJS templating and dynamic content.
- Nodemon for automatic server restart.

## Requirements
- Node.js and NPM.
- VS Code or any text editor.
- Web browser or Postman.

## How to Run

Install the required packages:

```bash
npm install express ejs
npm install nodemon -D
```

Start the server:

```bash
npm run dev
```

Open `http://localhost:3000` in your browser.

## Expected Output
The application responds to different routes, processes request data, and displays dynamic pages using EJS templates.

## Learning Outcome
Understand how to create backend web applications using Node.js, Express.js, HTTP requests, and EJS templating.
