# Lab Experiment 05: JavaScript Arrays, Objects, and Functions

## Objective
To demonstrate JavaScript arrays, objects, functions, and string methods.

## Files
- `script.js` – Basic array, object, and function examples.
- `script2.js` – String methods and array/object operations.
- `index.html` – Runs JavaScript in the browser.
- `library.js` – Book library management using arrays and objects.

## Concepts
- Arrays: `push()`, indexing, updating elements.
- Objects: Add, read, and update properties.
- Functions: Parameters, return values, and function calls.
- Strings: `toUpperCase()`, `toLowerCase()`, `split()`.
- PBL: Add and search books using functions.

## How to Run

Run using Node.js:

```bash
node script.js
node script2.js
node library.js
```

For browser execution, open `index.html` in a web browser.

## Expected Output
The programs demonstrate array and object operations, function execution, string transformations, and library book management.

## Learning Outcome
Understand how to use JavaScript arrays, objects, and functions to manage data in web applications.
